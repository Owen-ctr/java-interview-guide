# ID 与路由

## 什么是一致性哈希？解决什么问题？

<Badge type="warning" text="难度：深入" />

### 一句话答案
一致性哈希把节点和数据映射到同一 hash 环上，节点增减只影响环上相邻部分数据，避免普通取模那样大规模数据迁移，常用于 Redis 集群/缓存分片。

### 详细解析
- **问题**：`hash(key)%N` 在 N 变化时几乎所有 key 重新映射。
- **环 + 虚拟节点**：节点映射多个虚拟节点到环上，key 顺时针找最近节点；虚拟节点让负载更均衡。
- **应用**：缓存、分库分表路由、CDN。

## 常见分布式 ID 生成方案？

<Badge type="tip" text="难度：进阶" />

### 一句话答案
UUID（无序、太长）、数据库自增（分库不便）、雪花算法 Snowflake（时间戳+机器+序列，趋势递增）、号段模式 Leaf-segment（批量取号降 DB 压力）。

### 详细解析
- **Snowflake**：64 位，1 符号 + 41 时间 + 10 机器 + 12 序列；依赖时钟，时钟回拨会出问题（需处理）。
- **号段**：DB 一次取一段（如 1000 个）缓存在内存分配，DB 压力小；Leaf 双 buffer 预取更平滑。
- **趋势递增**利于数据库索引，比纯随机 UUID 更友好。
